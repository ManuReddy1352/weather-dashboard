# 🌦️ Weather Dashboard

A modern weather application built with React.

## Features

- Current weather
- Hourly & 5-day forecast
- Animated weather icons
- Rain, snow & wind effects
- Glassmorphism UI
- Fully responsive

## Tech Stack

- React
- OpenWeather API
- Framer Motion
- CSS

## Setup

```bash
npm install
npm run dev
```
